# Programming_Fundamentals_Patterns_and_Loops
"Collection of 11 C++ programs demonstrating loops, nested loops, and pattern printing for practice."
C++ Loop & Pattern Programs by Muhammad Furqan 

This repository contains 11 C++ programs that focus on loops, nested loops, and pattern printing. These programs are designed for practice and understanding of fundamental concepts in C++ such as for loops, nested loops, and basic output formatting.

Programs Included

Multiplication Table – Prints a 5×5 multiplication table.

Number Triangle – Prints a triangle with numbers increasing from 1.

Reverse Number Triangle – Prints a triangle with numbers decreasing in each row.

Same Number Triangle – Prints a triangle where each row contains the same number.

Reverse Count Triangle – Prints a triangle counting down from the current row number.

Alphabet Triangle – Prints a triangle using consecutive letters of the alphabet.

Square Pattern – Prints a 5×5 square of *.

Right-Angled Triangle – Prints a right-angled triangle using *.

Inverted Right-Angled Triangle – Prints an inverted right-angled triangle using *.

Hollow Square – Prints a hollow 5×5 square using *.

Print Number Multiple Times – Prints the number 1 twice in a 2×2 grid.

Key Concepts Practiced

Nested loops

Pattern printing

Character and number manipulation

Conditional statements (for hollow shapes)
