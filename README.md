> Collection of 11 C++ programs demonstrating loops, nested loops, and pattern printing for practice.

## C++ Loop & Pattern Programs by Muhammad Furqan

This repository contains 11 C++ programs that focus on loops, nested loops, and pattern printing. These programs are designed for practice and understanding of fundamental concepts in C++ such as for loops, nested loops, and basic output formatting.

## 📂 Programs Included

| # | Program | Description |
|---|---------|-------------|
| 1 | **Multiplication Table** | Prints a 5×5 multiplication table. |
| 2 | **Number Triangle** | Prints a triangle with numbers increasing from 1. |
| 3 | **Reverse Number Triangle** | Prints a triangle with numbers decreasing in each row. |
| 4 | **Same Number Triangle** | Prints a triangle where each row contains the same number. |
| 5 | **Reverse Count Triangle** | Prints a triangle counting down from the current row number. |
| 6 | **Alphabet Triangle** | Prints a triangle using consecutive letters of the alphabet. |
| 7 | **Square Pattern** | Prints a 5×5 square of `*`. |
| 8 | **Right-Angled Triangle** | Prints a right-angled triangle using `*`. |
| 9 | **Inverted Right-Angled Triangle** | Prints an inverted right-angled triangle using `*`. |
| 10 | **Hollow Square** | Prints a hollow 5×5 square using `*`. |
| 11 | **Print Number Multiple Times** | Prints the number 1 twice in a 2×2 grid. |

---

## 🧠 Key Concepts Practiced

- Nested loops
- Pattern printing
- Character and number manipulation
- Conditional statements (for hollow shapes)

## ⚙️ How to Compile & Run

```bash
g++ program_name.cpp -o program_name
./program_name
```

Replace `program_name` with the actual file name of the program you want to run.
